# Investor Pitch Deck — система

## Аудиторія / тон
Інвестор. Premium VC startup deck. UA. 16:9. Restrained deep-blue accent.

## Типографіка
- Headlines + body: **Manrope** (geometric grotesk, Cyrillic)
- Labels/eyebrows + figures: **JetBrains Mono** (Cyrillic)

## Палітра
- Ink #0A0A0B, Graphite #16161A, Slate #6B6B72 (muted)
- Paper #FAFAF9, White #FFFFFF, hairline rgba(10,10,11,.10)
- Accent #2563EB (deep blue) — лише на ключових цифрах + один hero-елемент на слайд
- Темні слайди: cover (1), інвест-модель (7), фінал (15)

11 Фінансова модель ліцензування

## Layout system
- Eyebrow row: mono, NN · LABEL, slide number in accent
- Title: Manrope 700, -0.02em, large
- Light slides default; 3 dark for rhythm/emphasis
- Diagrammatic, abstract dashboards (no fake screenshots)
- Cards: white, 1px hairline, 18px radius, generous pad
- Bottom padding reserved structurally
